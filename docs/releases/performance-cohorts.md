# Performance cohorts

`performance-cohorts.mjs` provides read-only GitHub Actions artifact discovery. It does not build native code or reuse head native binaries for the base.

- `discoverBaseCohort({repository, revision, abi, api?})` finds a successful same-repository `ci.yaml` push or PR run with the exact source head SHA. It requires the core and every Commerce Rust plugin artifact. The artifact producer prefix may be a synthetic merge SHA only when GitHub's Git commit API independently proves that its tree equals the exact requested source tree. Missing, expired, unauthorized and incompatible cohorts yield `current-only` with a reason.
- `prepareBaseConsumer({baseRoot, revision, cohort, protocol, api?})` verifies an already checked out base SHA and the sampling protocol/Commerce source prerequisites, then downloads and materializes exact ABI artifacts into that checkout. Its paired receipt includes artifact IDs and binary hashes. Checkout and JavaScript dependency installation/build are the workflow caller's responsibility. Only start base sampling after those commands succeed. Run base and head sequentially in the same job/runner; never compare a historical timing as the paired base.
- `loadComparableHistory({repository, abi, metadata, currentRunId?, api?})` reads at most ten earlier trusted successful workflow runs and their retained performance artifacts. It accepts only complete summaries matching protocol, fixture hash, Node, pnpm, OS, architecture, runner image/version and lockfile hash. Results contain sanitized timing cells and producer/source revisions. Missing, expired, incompatible and invalid evidence remain separate exclusions. History is descriptive per OS; no cross-OS ranking is produced.

The caller supplies `GITHUB_TOKEN` with Actions read permission. REST requests have a 30-second timeout, bounded run/artifact listings, and 128 MiB archive limits. ZIP parsing rejects traversal, Windows path escapes, symlinks, encrypted/unsupported formats, duplicate files and oversized output; native archives must contain exactly the expected single binary. No archive-supplied executable is invoked during extraction.

Tests use injected REST mocks and never access the network: `node --test scripts/performance-cohorts.test.mjs`. Initial base revisions without this protocol or retained native artifacts legitimately remain current-only. Artifact retention is the existing GitHub Actions retention policy; this helper creates no external storage or credentials.
