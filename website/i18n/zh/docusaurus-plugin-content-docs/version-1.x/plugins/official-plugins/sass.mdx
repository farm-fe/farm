# @farmfe/plugin-sass

支持 `sass` 编译

## Installation

<Tabs>
  <TabItem value="npm" label="npm">
    <CodeBlock language="javascript" code={"npm install @farmfe/plugin-sass"} />
  </TabItem>
  <TabItem value="yarn" label="yarn">
    <CodeBlock language="javascript" code={"yarn add @farmfe/plugin-sass"} />
  </TabItem>
  <TabItem value="pnpm" label="pnpm">
    <CodeBlock language="javascript" code={"pnpm add @farmfe/plugin-sass"} />
  </TabItem>
</Tabs>

## Usage
`@farmfe/plugin-sass` 是一个 Rust 插件，你只需要在 `farm.config.ts` 的 `plugins` 字段中配置它的包名。
```ts {4}
import { UserConfig } from '@farmfe/core';

const config: UserConfig = {
  plugins: ['@farmfe/plugin-sass', { /** options here */}]
}
```

## Options
### additionalData
* **类型**: `string`

在每个 `sass` 文件头部添加额外内容，例如 `@import '@/styles/variables.scss';` 语句。
