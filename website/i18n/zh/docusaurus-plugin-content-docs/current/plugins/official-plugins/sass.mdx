# @farmfe/plugin-sass

支持 `sass` 编译

  <TabItem value="npm" label="npm">

  </TabItem>

## Usage
导入 `@farmfe/plugin-sass` 并在 `farm.config.ts` 的 `plugins` 字段中以工厂函数的形式调用，与 JS 插件用法一致。
```ts {2,5}
import { UserConfig } from '@farmfe/core';
import sass from '@farmfe/plugin-sass';

const config: UserConfig = {
  plugins: [sass({ /** options here */ })]
}
```

## Options
### additionalData
* **类型**: `string`

在每个 `sass` 文件头部添加额外内容，例如 `@import '@/styles/variables.scss';` 语句。
