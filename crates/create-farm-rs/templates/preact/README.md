# Farm + Preact

This template should help you start developing using Preact and TypeScript in Farm.

## Setup

The included pnpm configuration keeps virtual-store directory names short enough for Node 20 ESM package resolution on Windows.

Install the dependencies:

```bash
pnpm install
```

## Get Started

Start the dev server:

```bash
pnpm start
```

Build the app for production:

```bash
pnpm build
```

Preview the Production build product:

```bash
pnpm preview
```

Clear persistent cache local files

```bash
pnpm clean
```
